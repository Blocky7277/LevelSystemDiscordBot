## About The Project

A simple leveling bot written in [discord.js](https://discord.js.org)

#### Why:

- Encourages engagement within a server
- I have seen a few node modules implementing a leveling server but none of them worked how I wanted them to

<!-- GETTING STARTED -->

## Getting Started

Clone the repo <br>
`git clone https://github.com/Blocky7277/LevelSystemDiscordBot.git`

Install npm dependencies
`npm i`

Create a .env file in the project directory and set it up as such

```
    TOKEN={DISCORD_BOT_TOKEN}
    MONGODB={MONGODB_API_KEY}
```

## Usage

Chat in discord to gain levels
Then use /level to check your level
